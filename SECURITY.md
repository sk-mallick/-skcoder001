## Reporting a Vulnerability

If you discover a potential security vulnerability in this project, please
do not disclose it publicly.

Instead, please send an email directly to `subhammallick454@gmail.com`.
We take all security vulnerabilities seriously and will work to verify and
resolve the issue promptly.

Please include the following information in your report:

* The type of vulnerability (e.g., XSS, SSRF).
* Step-by-step instructions to reproduce the vulnerability.
* Any potential impact you have identified.

You should receive a response within 48 hours acknowledging receipt of your
vulnerability report.
