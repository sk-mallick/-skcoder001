## Reporting a Vulnerability

Security is a high priority. If you discover any security-related issues in this profile repository or its associated projects, please report it safely.

**Do not open a public issue.** Instead, please send an email to the contact address listed in the profile (subhammallick454@gmail.com).

Please include the following information in your report:
* The type of vulnerability
* Detailed steps to reproduce the vulnerability
* The potential impact

I will endeavor to acknowledge your report within 48 hours, and provide an expected timeline for resolution.
