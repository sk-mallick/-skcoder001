# Security Policy

Currently, the default branch (`main` or `master`) of this repository
is supported with security updates.

| Version | Supported          |
| ------- | ------------------ |

## Reporting a Vulnerability

If you discover a security vulnerability within this repository,
please do **not** report it by creating a public GitHub issue.

Instead, please send an email to **<subhammallick454@gmail.com>**.
I will review your report and respond as soon as possible.
