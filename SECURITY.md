# Security Policy

## Supported Versions

Currently, this repository is a static profile and does not maintain versions.
If any codebase changes occur, security updates will apply to the main branch.

## Reporting a Vulnerability

Please report any security vulnerabilities via email.

Email: <subhammallick454@gmail.com>

We take all security reports seriously. When we receive a report, we will:

1. Acknowledge receipt of your report.
2. Investigate the issue to determine its impact.
3. Work on a fix as quickly as possible if the issue is verified.
4. Notify you when the issue has been resolved.

Please do not open a public issue for security vulnerabilities.
