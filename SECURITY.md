# Security Policy

## Supported Versions

This repository currently contains static files. As such, versioning is not
strictly enforced in the traditional software sense.

## Reporting a Vulnerability

If you discover any security-related issues in this repository, please do not
disclose it publicly.

Instead, report it directly to the repository maintainer via email at:
[subhammallick454@gmail.com](mailto:subhammallick454@gmail.com)

Please provide a detailed description of the vulnerability and the steps to
reproduce it. We will try to respond to your report as soon as possible.
