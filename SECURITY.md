# Security Policy

## Supported Versions

We take the security of our project seriously. Currently, only the main
branch is actively supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| Main    | :white_check_mark: |

## Reporting a Vulnerability

Please report any security vulnerabilities by emailing
`<subhammallick454@gmail.com>`.

We will respond to your report as quickly as possible, typically within 48
hours. Please do not disclose vulnerabilities publicly until a fix has been
released.
