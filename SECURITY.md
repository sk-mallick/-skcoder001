# Security Policy

## Supported Versions

This project is a static GitHub profile documentation project, so versioning
does not apply. Security updates are applied continuously to the `main` branch.

| Branch | Supported          |
| ------ | ------------------ |
| main   | :white_check_mark: |

## Reporting a Vulnerability

Please report any security vulnerabilities via email to
<subhammallick454@gmail.com>.

I will respond as quickly as possible to acknowledge the report and
coordinate a fix.
