
## 2024-05-21 - [Added SECURITY.md Policy]
**Vulnerability:** The repository lacked a documented process for responsibly reporting security vulnerabilities.
**Learning:** Static GitHub profile repositories often omit vulnerability reporting policies, leading to the risk of users irresponsibly disclosing security issues in public issues or pull requests.
**Prevention:** Always ensure a `SECURITY.md` file is present in the repository root to outline the reporting process and prevent public disclosure of vulnerabilities.
