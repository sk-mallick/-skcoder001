## 2024-05-15 - Missing alt attributes on dynamic GitHub profile components
**Learning:** Dynamic components inserted into markdown, such as capsule renders and stat cards (e.g. GitHub activity graphs and streak stats), often omit `alt` attributes. These are crucial for screen readers to properly interpret the visual data being conveyed on a GitHub profile.
**Action:** Always verify that third-party image generation APIs (like `capsule-render` and `github-readme-stats`) are appended with descriptive `alt` tags when embedded via `<img>` tags in markdown documentation.

## 2024-08-17 - Empty Markdown links on decorative badges
**Learning:** Decorative badges generated by third-party services (like shields.io) are sometimes wrapped in empty Markdown links (e.g., `[![alt](url)]()`) to make them inline blocks or mimic link structures. This creates unnecessary, empty focusable elements that confuse keyboard navigation and screen readers.
**Action:** When auditing static markdown files (like profile READMEs) for accessibility, strip empty link wrappers from decorative or static images to improve keyboard navigation and screen reader experience.
